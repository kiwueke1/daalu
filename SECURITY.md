# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/kiwueke1/daalu/security/advisories/new),
not as public issues. We'll acknowledge reports within a few days.

Daalu runs an AI agent that can propose changes to your infrastructure. Reports
about bypassing the human-approval gate on write actions, crossing tenant
boundaries, or reaching a cluster over the WireGuard mesh without authorization
are especially welcome.
